# Codenote

실행 기능이 없는 간단한 Electron 텍스트·코드 편집기입니다.

## 실행 및 빌드

- `npm install`
- `npm start`: 앱 실행
- `npm test`: 빌드 및 Electron 통합 검사
- `npm run pack`: `release/win-unpacked/Codenote.exe` 생성 (설치 프로그램 생성 안 함)
- `node tests/packaged-smoke.cjs`: 빌드된 실행 파일과 폰트 로드 검사

새 파일, 열기, 저장, 다른 이름으로 저장, 파일 메뉴의 최근 파일 12개, 폴더 탐색기, 실행 취소/다시 실행, 찾기/바꾸기와 라이트/다크 모드를 제공합니다. 문서를 바꾸거나 종료할 때 미저장 내용을 확인합니다.

언어별 하이라이트와 자동완성은 없습니다. 확장자와 관계없이 숫자, 괄호 `()[]{}`, 작은따옴표·큰따옴표 안의 내용만 색으로 구분합니다. 이스케이프된 따옴표와 세 개의 따옴표로 감싼 여러 줄 문자열도 지원합니다. 키워드·함수·주석은 별도 색을 적용하지 않습니다.

저장·열기 대화상자는 모든 파일을 기본으로 표시합니다. 새 파일의 기본 이름은 확장자가 없는 `Untitled`이며, 사용자가 입력한 파일명을 그대로 사용합니다. py, r, txt, html 외의 텍스트 파일도 열 수 있습니다. UTF-8로 읽고 저장하며 CRLF/LF 줄바꿈을 유지합니다.

Ctrl+N 새 파일 · Ctrl+O 열기 · Ctrl+Shift+O 폴더 열기 · Ctrl+S 저장 · Ctrl+Shift+S 다른 이름으로 저장 · Ctrl+Z 실행 취소 · Ctrl+Y 다시 실행 · Ctrl+F 찾기/바꾸기 · Ctrl+B 탐색기

줄 번호는 편집기 왼쪽에 표시합니다. 하단에는 커서 열, 현재 줄 길이, 전체 줄 수를 표시합니다. 줄 길이는 줄바꿈을 제외한 문자 수이며 탭은 1문자로 계산합니다. 커서 열은 UTF-16 위치 기준입니다. 탐색기는 폴더를 펼칠 때 읽으며 새로고침 버튼으로 갱신합니다. 심볼릭 링크는 표시하지 않습니다.

UI는 markdoc의 배경색과 구조를 참고하고 Pretendard Medium/Bold를 사용합니다. 편집기에는 D2Coding Ver1.4.0을 사용합니다. 폰트 라이선스는 동봉한 라이선스 파일을 참고하세요.
